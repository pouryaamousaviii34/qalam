# EXTRACTION_NOTES — PHASE E

## ۱. محدودیتِ بنیادی: OCR در دسترس نبود
- PDF **اسکن/تصویری** است: `pdftotext` روی کلِ ۴۹ صفحه فقط **۴۹ نویسه** برمی‌گرداند (جداکنندهٔ صفحه).
  متادیتای PDF هم `Title: AK (00).gif` است، یعنی از GIFهای اسکن ساخته شده.
- `tesseract` نصب نیست. نصبش ناموفق بود:
  - `pip3 download pytesseract` → خطای درونیِ pip (`PoolKey.__new__() got an unexpected keyword argument`) و سپس core dump.
  - `apt-get download tesseract-ocr` → `502 Bad Gateway` از پراکسی.
- **نتیجه:** استخراجِ متن به‌صورتِ ماشینی انجام **نشد**. تمامِ متنِ نقل‌شده در این دادگان، از **خوانشِ چشمیِ تصویرِ رندرشده** است.
  به همین دلیل بسیاری از قواعد `SOURCE_EXPLICIT` هستند (متن را خوانده‌ام) ولی نقلِ *دقیقِ نویسه‌به‌نویسه* را تضمین نمی‌کنم.

## ۶. هشدارِ مهم دربارهٔ «ع»
ترتیب و جهتِ چهار حرکتی که در فازهای A–D پروژه برای «ع» استفاده شد، از **تصویرِ ارسالیِ کاربر** آمده است، نه از این کتاب. این کتاب فلش یا شمارهٔ ترتیبِ حرکت ندارد. → `CONFLICT-004`.
